# Sentinel X 研究版 — 使用手冊

適用版本：0.15.1。Sentinel X 是 Windows 上的資安研究工具：掃描檔案、整理各引擎的證據、
判定風險、隔離威脅、被動觀察系統行為，並產生研究報告。

> 沒有任何防毒工具能偵測所有威脅。「未發現威脅」代表目前安裝的引擎與規則沒有發現問題，
> 不代表檔案一定安全。Sentinel X 只讀取與分析檔案，**絕不執行**被分析的檔案，也**不會自動永久刪除**任何檔案。

---

## 1. 安裝與解除安裝

- 執行 `SentinelX-0.15.1-setup.exe`。只安裝給目前的使用者，**不需要系統管理員權限**，
  預設位置 `%LOCALAPPDATA%\Programs\SentinelX`。
- 需求：Windows 10 或 11（64 位元）。安裝檔已內含 ClamAV 1.5.4。
- 解除安裝：Windows「設定 → 應用程式」中的 Sentinel X。程式會被移除，但**你的資料不會被刪除**：
  設定、資料庫、稽核紀錄、報告與**隔離區中的檔案**都保留在 `%LOCALAPPDATA%\SentinelX`，需要時請自行刪除。
- 同一個資料資料夾只能開一個 Sentinel X 視窗；再開一次會顯示「已經在執行中」。

## 2. 第一次啟動：ClamAV 病毒碼

ClamAV 需要病毒碼才能偵測威脅。第一次啟動時 Sentinel X 會詢問：
是否允許從 ClamAV 官方伺服器（`database.clamav.net`，Cisco Talos 營運）下載病毒碼。

- 選「是」：切到「設定」頁並開始下載（第一次約數百 MB，需要數分鐘，可取消）。
- 選「否」：不會連網。之後可在「設定 → ClamAV 病毒碼」勾選同意並按「立即更新病毒碼」。
- 同意之後，Sentinel X **每天自動更新一次**（視窗開著或在系統匣時）。失敗會在 2 小時後重試，並在系統匣通知你。
  可在「設定 → ClamAV 病毒碼」關閉「每天自動更新病毒碼」，或隨時按「立即更新病毒碼」。
- Sentinel X 完全關閉時不會更新；建議開啟即時防護，讓它在系統匣常駐。
- 病毒碼存放在 `%LOCALAPPDATA%\SentinelX\clamav-db`，不需要系統管理員權限。

### 手動更新（進階）
也可以自己執行內附的 freshclam：

```powershell
$db = "$env:LOCALAPPDATA\SentinelX\clamav-db"; New-Item -ItemType Directory -Force $db | Out-Null
"DatabaseDirectory $db`nDatabaseMirror database.clamav.net" | Set-Content -Encoding ascii "$env:LOCALAPPDATA\SentinelX\freshclam.conf"
& "$env:LOCALAPPDATA\Programs\SentinelX\clamav\freshclam.exe" "--config-file=$env:LOCALAPPDATA\SentinelX\freshclam.conf"
```

若你另外安裝了 ClamAV，可以在「設定 → 偵測引擎」指定 `clamscan.exe` 路徑與病毒碼資料夾，
或改用已啟動的本機 `clamd`（只允許本機位址）。

## 2a. VirusTotal（查詢全球 70 多家防毒）

開啟後，檢查程式、安裝檔、腳本、壓縮檔與文件時，Sentinel X 會把檔案的「指紋」（SHA-256）送到 VirusTotal，
看其他防毒公司怎麼判斷。**只送指紋，不上傳檔案。**

1. 「設定 → VirusTotal」勾選同意。
2. 按「1. 註冊免費帳號」，在 VirusTotal 網站註冊並登入。
3. 按「2. 打開我的 API 金鑰頁面」，複製 64 個字元的金鑰，貼到欄位後按「儲存金鑰」。金鑰以 Windows 加密存在你的帳號下，存好後不會再顯示。
4. 按「4. 測試連線」：會查詢無害的 EICAR 測試檔，看到「連線成功」就完成了。

判斷方式：25 家以上**而且**超過一半判定惡意＝強證據；10 家以上＝中等證據（常是破解工具、遊戲外掛等灰色軟體，只判「可疑」）；10 家以下＝弱證據。VirusTotal 的結果裡本來就包含 ClamAV，所以兩者不算兩個獨立的證據。**只有 VirusTotal 判定有危險時，即時防護不會自動隔離或關掉程式**，只會鎖住並通知你確認。VirusTotal 最後一次分析超過 180 天的「0 家判毒」只當參考。
免費帳號每分鐘 4 次、每天 500 次（每天台灣時間早上 8 點重置，和 VirusTotal 一致）；超過時那個檔案只是「這次不查」，不影響其他檢查。即時防護只查詢下載、桌面、文件與 USB 裡的檔案，不等待，每天最多用 350 次，其餘留給手動掃描。查過的結果會保留 3 天。

## 3a. 即時防護

在「即時防護」頁面開啟。開啟後：

- **全域防護（預設開啟）**：所有硬碟（C:、D:…）與插入的 USB 隨身碟、記憶卡上新增或修改的檔案，寫完後數秒內用所有引擎掃描（ClamAV 以常駐方式執行，約佔 1 GB 記憶體）。為了不拖慢電腦，會跳過 Windows 系統資料夾（Windows\Temp 仍會檢查）、其他防毒軟體的隔離區、試跑室的虛擬硬碟、瀏覽器快取與系統記錄檔。關閉全域防護時，只檢查下載、桌面、文件、暫存資料夾與 USB。
- **自動隔離**：「確認威脅」會自動移入隔離區（不刪除，可還原）；「可疑」只通知。可關閉。
- **終止威脅程序**：執行檔與「確認威脅」或隔離區中檔案的 SHA-256 完全相同的程序會被終止，包括從隔離區拿出來的副本。Windows 重要程序、微軟簽章的程式與 Sentinel X 自己不會被終止（只通知）。可關閉。
- **隔離區監看**：隔離區被其他程式變更時立刻通知。
- **下載檢查**：下載資料夾中新的安裝檔與執行檔，檢查完會通知結論與理由，例如「有效數位簽章：○○公司」或「沒有數位簽章、來自網際網路，請確認來源可信」。結論不會說「安全」。
- **執行前鎖住**：下載、桌面、文件與 USB 中新出現的程式（.exe、.com、.scr、.cpl、.dll、.pif）會立刻被鎖住，檢查完成前按兩下會顯示「存取被拒」。沒有發現威脅就自動解鎖（通常幾秒內）；確認威脅會被隔離，可疑檔案會一直鎖住，要在「即時防護」頁面的「已鎖住的檔案」選取後按「解鎖」。可關閉。.msi 安裝檔、腳本，以及 Program Files、暫存資料夾等其他位置不會被鎖住，只會掃描（安裝程式會在那些地方建立程式並立刻執行，鎖住會讓安裝失敗）。
- **盯住開機自動執行（預設開啟）**：病毒最常把自己設成每次開機都自動執行。Sentinel X 每 30 秒讀一次（只讀不改）登錄機碼 Run／RunOnce、啟動資料夾、自動啟動的服務，排程工作每 5 分鐘一次。第一次讀到的是「原本就有的」，之後新加入的項目（包括 Sentinel X 沒在執行時加入的）會立刻掃描它要啟動的程式：確認威脅會照常自動隔離；可疑、沒有有效數位簽章、或找不到程式檔時會通知你；有效簽章且未發現威脅的只記錄在活動紀錄。Sentinel X 不會自動刪除任何開機項目。沒涵蓋：WMI 訂閱、瀏覽器擴充功能、Winlogon／AppInit 等少見位置與驅動程式。
- **勒索病毒警報（預設開啟）**：在文件、桌面、下載、圖片、影片、音樂與 OneDrive 資料夾中，20 秒內有 10 個以上文件被改成奇怪的副檔名（例如 `報告.docx.locked`），或出現 10 個以上「文件名＋奇怪副檔名」的新檔同時有 10 個以上文件被刪除，就跳出紅色警報；150 個以上文件被修改則是黃色提醒（也可能是同步或備份）。警報會列出最近寫入最多的程式，在「即時防護」頁面選取後按「停止選取的程式」（會再問一次），Windows 必要程式不能停止。Sentinel X 不會自動停止程式。限制：警報出現時已經有一些檔案被改了；加密很慢或不改副檔名的病毒可能不會觸發；以系統管理員身分執行的程式可能列不出來。
- **防勒索誘餌檔（預設關閉）**：開啟後在上述資料夾各放一個隱藏資料夾「!!SentinelX 防勒索誘餌（請勿修改）」，內含 4 個假文件與說明（約 70 KB）。一般程式不會碰它們，被修改、改名或刪除就立刻紅色警報（只看內容，OneDrive 改屬性不算）。關閉時只移除 Sentinel X 自己沒被改過的誘餌檔。
- **無法完整檢查的新程式**：引擎出錯或逾時時，新程式不會被當成檢查過而解鎖；會保持鎖住，20 秒、1 分鐘、3 分鐘後重試，仍然失敗就通知你，確認來源可信後可以在「即時防護」頁面解鎖。別的程式（或你自己）已經封鎖執行的檔案，Sentinel X 不會接手，也不會把它解開。
- **被干擾時一定會知道**：Sentinel X 上次沒有正常結束（被其他程式結束、當機或斷電）、設定檔在它沒執行時被改過、「登入時自動啟動」被移除（會自動恢復），下次啟動都會通知你並寫入稽核紀錄。它無法阻止同一個使用者身分的程式這樣做（那需要系統服務或驅動程式），但不會讓它悄悄發生。
- **省記憶體模式（預設關閉，給 8 GB 以下的電腦）**：ClamAV 不常駐，約省 950 MB 記憶體。下載、桌面、文件與 USB 的檔案仍用 ClamAV 檢查（每批臨時載入病毒碼，比較慢）；其他位置只用 YARA、雜湊比對和 VirusTotal。記憶體夠用就不要開。
- **病毒偵測規則檔**：YARA 規則（.yar）或 ClamAV 文字病毒碼檔本來就含有病毒特徵，所以會被偵測到；即時防護不會自動隔離這種純文字規則檔，只會通知你，檔案仍列在「需要處理的檔案」由你決定。
- **紀錄保存**：即時防護的掃描紀錄保留 30 天；有偵測、無法完整檢查或判定不是「未發現威脅」的紀錄會一直保留。
- **背景執行**：關閉視窗後在系統匣繼續防護；可設定登入 Windows 時自動啟動。要完全結束，請在系統匣圖示按右鍵選「結束」。

**限制**（請務必了解）：
- 這是 Windows Defender 之外的第二道防線。沒有核心驅動程式：除了上述位置的新程式（執行前鎖住），其他檔案無法在**執行前**攔截；一建立就立刻被執行時，可能搶在掃描之前。
- 終止威脅程序以每秒檢查的方式進行，威脅可能已執行約一秒。
- 試跑室（見 3b 節）可以在虛擬機裡觀察檔案的行為，但惡意程式能偵測虛擬機而裝乖，任何沙盒都無法證明軟體無毒。

## 3b. 試跑室（虛擬機）

> 2026-11-08 起可以使用：在這台電腦上實際建立假電腦，並用 4 個無害測試檔驗證通過（安靜檔沒有發現、開機自動執行被抓到、40 份誘餌文件被改名判定為強烈證據、EICAR 測試檔被虛擬機裡的 Defender 偵測到）。

想安裝不確定的軟體時，先在「試跑室」頁面選擇檔案。Sentinel X 會把它放進一台**沒有網路**的 Windows 虛擬機執行，觀察 1～30 分鐘（預設 2 分鐘；會先等一下才發作的病毒用 10 或 30 分鐘），結束後虛擬機整台還原。每次試跑前虛擬機會先重新開機（約 3～6 分鐘）。你的電腦不會執行這個檔案。

- 觀察的行為：新增開機自動執行（登錄、啟動資料夾、服務、排程工作、WMI）、改動或刪除 40 份誘餌文件（像勒索病毒）、關閉 Windows Defender、修改 hosts 檔、放置新程式、嘗試連線；虛擬機裡的 Windows Defender 偵測到也算。
- 結果會和一般掃描一樣成為證據與判定；確認威脅時可以直接隔離。沒看到可疑行為**不代表安全**。
- 這是一台單純的虛擬機，沒有偽裝成一般電腦：會偵測虛擬機的病毒可能裝乖，所以結果永遠不會說「安全」。檔案在虛擬機的一般權限帳號下執行。
- 需要：VirtualBox、Windows 11 企業版評估映像檔（存在 `%USERPROFILE%\SentinelX-Sandbox\iso`）、約 4 GB 記憶體與 20～40 GB 硬碟（虛擬硬碟最大 64 GB，實際只用寫入的部分）。第一次按「建立試跑室」會自動安裝（約 1～2 小時）。安裝期間虛擬機會暫時連上網路，向微軟啟用免費評估版（不啟用的話 Windows 會顯示授權過期並每小時自動關機）；那時裡面還沒有任何要測試的檔案，啟用後網路卡會整個移除再存成乾淨狀態，之後試跑一律沒有網路。評估映像檔請到微軟 Evaluation Center 下載一般的「Enterprise」版（不是 LTSC 版，LTSC 評估檔較舊），可用微軟公布的 SHA-256 確認檔案正確；資料夾裡有多個映像檔時會用最新的那個。
- **VirtualBox 要保持最新**：試跑的安全取決於 VirtualBox 本身（舊版可能有讓虛擬機裡的程式跑到你電腦上的漏洞）。每次建立試跑室或試跑前，Sentinel X 會向 VirtualBox 官方網站讀取最新版本號（一天一次，不送出你電腦的任何資料）；你的版本比較舊就不會試跑，頁面會請你到 https://www.virtualbox.org/wiki/Downloads 更新。暫時沒有網路時會用上次記住的版本比較，並說明無法連線確認。Sentinel X 不會自動幫你下載或安裝 VirtualBox。
- Windows 評估版可用 90 天；第 80 天起 Sentinel X 會用已下載的映像檔自動重建，完成後通知你。
- 若電腦開著「記憶體完整性」，VirtualBox 只能以 1 顆 CPU 執行虛擬機，所以試跑會比較慢；請不要為此關閉記憶體完整性。

## 4. 掃描與判定

1. 在「掃描中心」加入檔案或資料夾，按「開始掃描」。進度會即時顯示，可隨時取消。
2. 每個檔案會得到一個分類：

| 分類 | 意思 |
|---|---|
| 確認威脅 CONFIRMED_THREAT | 有高可靠度的證據（例如 ClamAV 病毒碼命中） |
| 可疑 SUSPICIOUS | 有中等可靠度的證據，需要人工判斷 |
| 未知 UNKNOWN | 無法完整評估（權限、大小上限、引擎錯誤…），**不代表安全** |
| 未發現威脅 CLEAN | 可偵測的引擎都完整檢查過且沒有發現 |

- 「排序分數」只用來排列清單，**不是**惡意程式的機率。
- 沒有數位簽章**不等於**惡意；有效簽章也只證明來源與未被竄改。
- 超過大小上限、權限不足、連結與交接點都會列為「未完成評估」，不會被當成乾淨。
- Sentinel X 自己的資料資料夾不會被掃描（裡面的規則與報告本來就含有規則要找的字串）。

## 5. 審查與隔離

- 「威脅中心」中選一筆判定，查看每個引擎的證據（引擎、版本、規則、證據、時間、SHA-256、說明）。
- 人工審查：「確認為威脅」「標記為誤判」「需要進一步分析」，都必須填原因。誤判可以只排除命中的規則，或排除整個檔案。審查不會刪除任何證據。
- 隔離：只有「確認威脅」可以隔離，必須填原因並再次確認。檔案會以混淆格式存入只有你能存取的隔離區，原檔才會移除。
- 還原：在「隔離區」頁面。還原前會重新驗證 SHA-256，不會覆蓋既有檔案，並保留下載來源標記。還原後檔案可以被執行，只有確定是誤判時才還原。
- **還原後重新下載又被擋？** 單純「還原」只放出這一次，不代表信任這個檔案：重新下載同一個檔案時，它仍會被當成威脅。還原時 Sentinel X 會問你「也標記為誤判？」，選「是」之後，內容「完全相同」的檔案（用 SHA-256 判斷）不論在哪裡出現，都不會再被隔離、鎖住或在執行時被關掉；檔案只要有一點不同（例如新版本）仍會重新檢查。當時選了「否」的話，可以到「需要處理的檔案」選取它，按「標記為誤判」並勾選「排除整個檔案」。想取消信任：「需要處理的檔案 → 誤判排除」移除那一筆，相關檔案會立刻重新判定。標記前就已經被鎖住的程式不會自動解鎖，請到「即時防護」頁面解鎖。
- 永久刪除：在「隔離區」選取項目後按「永久刪除…」並確認。刪除後無法復原；紀錄（路徑、SHA-256、原因）會保留，同樣內容的檔案之後仍會被認出並擋下。不確定時請保留在隔離區，放在那裡不會造成危害。Sentinel X 不會自己刪除任何檔案。

## 6. 行為監控

- 只觀察、不動作：不會結束程序、不會封鎖連線、不會變更任何設定。
- 來源：程序與網路（輪詢）、你指定的資料夾、Microsoft Defender 偵測記錄；以系統管理員身分重新啟動後，可讀取安全性記錄（需要開啟「稽核程序建立」）與 Sysmon。
- Sysmon 需自行從微軟官方網站下載安裝，頁面上有步驟與建議設定檔；Sentinel X 不會替你安裝。
- 每則警示分成「觀察到的事實」與「分析推論」，推論會列出無害的可能原因。

## 7. 研究實驗室

- 檢視樣本：MD5／SHA-1／SHA-256、檔案類型、下載來源標記、PE 結構（區段、匯入、版本資訊）、數位簽章與憑證鏈。
  PE 與簽章在獨立的分析程序中解析（時間與記憶體受限、不能再啟動程式），可隨時取消。
- 只輸入 SHA-256 也能查詢情報、已儲存的證據與歷史。
- YARA 測試：撰寫或載入規則，對你選的**無害**檔案測試。測試規則不會加入掃描、不影響判定。
- 檔案比較、分析時間軸、匯出研究報告（JSON／HTML／PDF）。

## 8. 威脅情報與 YARA 規則更新

- **雜湊清單**：「威脅情報 → 雜湊情報」匯入文字檔，每行一個 SHA-256，可加「,名稱,分類」。
  選擇可信度（高／中／低）與預設分類（惡意／已知良好）。不在任何清單中代表「未知」。
- **YARA 規則**：「威脅情報 → YARA 規則」加入 `.yar` 檔並填版本。規則會被複製並鎖定雜湊；
  原檔之後的修改不會生效，要更新請以新版本重新加入，再停用或刪除舊版。
  只允許安全的 YARA 模組（pe、elf、math、hash、time、string、dotnet），不允許 `include`。
- 建議流程：先在「研究實驗室 → YARA 測試」用無害檔案測試，確認沒有誤判再加入。
- 規則的 `meta` 可設定 `severity`（info／low／medium／high／critical）或 `score`（0～100，80 以上視為高）與 `confirming = true`（作者認為高可靠度）。
- **YARA Forge 公開規則**：「設定 → YARA 規則」勾選同意後，Sentinel X 會從 GitHub（YARAHQ/yara-forge）下載誤判最少的「核心」規則（約 5000 條），核對 GitHub 公布的 SHA-256，通過安全檢查才啟用，之後每週自動更新並移除舊版。

## 9. 報告

- 研究報告、檔案比較報告與掃描報告，每種都可輸出 JSON、HTML、PDF。
- 每份報告都附原始證據與產生當下的工具版本；檔案的 SHA-256 會記錄在資料庫與稽核紀錄。
- 「報告」頁會比對完整性：已被修改的報告開啟前會要求確認，也不能另存複本。

## 10. 設定

掃描上限、YARA 逾時、引擎啟用、ClamAV 路徑與 clamd、病毒碼、行為監控、記錄等級。
掃描、引擎與記錄設定在重新啟動後生效（頁面上有「重新啟動 Sentinel X」），監控設定在下次開始監控時生效。
所有變更都記錄在稽核紀錄中。

## 11. 資料與隱私

- 所有資料只存在本機 `%LOCALAPPDATA%\SentinelX`。Sentinel X 只有在你同意並按下更新時，才會連到 ClamAV 官方伺服器下載病毒碼；不會上傳你的檔案。
- 稽核紀錄以雜湊鏈保存，竄改可被偵測（儀表板會顯示「雜湊鏈中斷」）。

## 12. 疑難排解

| 狀況 | 處理 |
|---|---|
| ClamAV 顯示「病毒碼資料夾不存在」 | 到「設定 → ClamAV 病毒碼」更新病毒碼 |
| 掃描結果是 PARTIAL | 有檔案無法完整評估，原因列在掃描紀錄中 |
| 安全性記錄「需要系統管理員」 | 在「行為監控」按「以系統管理員身分重新啟動」 |
| 「已經在執行中」 | 已有一個 Sentinel X 視窗開著 |
| PDF 報告失敗 | 系統沒有可嵌入的中文字型（預設使用微軟正黑體） |
| 程式記錄 | `%LOCALAPPDATA%\SentinelX\logs`（「設定 → 開啟記錄資料夾」） |
