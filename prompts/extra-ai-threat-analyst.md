Implement Sentinel X AI Threat Analyst.

Purpose:
Use an AI model to explain security evidence generated by Sentinel X.

Capabilities:
- Explain ClamAV results.
- Explain YARA matches.
- Summarize PE metadata.
- Explain suspicious indicators.
- Compare independent engine findings.
- Generate readable investigation reports.

Requirements:
- AI must never independently declare a file malicious without evidence.
- Clearly distinguish facts, hypotheses, and unknowns.
- Treat file contents as untrusted data.
- Never execute files.
- Never upload files without explicit user consent.
- Support offline operation without AI.
- Never allow AI output to trigger automatic deletion or quarantine.
- The AI module is an analysis assistant, not the detection authority.
